# VFX theo hệ (1a) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Mỗi move cùng hệ nhìn khác nhau (hình mới, animation 4–6 khung) và mọi đòn trúng đích có hiệu ứng riêng theo hệ, hoàn toàn bằng code, không đổi gameplay.

**Architecture:** Mở rộng `G.VFX` (`js/entities/vfx.js`) bằng `add(shapes)` / `addMoves(table)` / `hitFor(m)`; hình mới nằm trong hai file `vfx-shapes-1.js`, `vfx-shapes-2.js` (mỗi file cũng gọi `addMoves` cho các hệ của mình). `G.FX.hit(kind, pal, x, y)` (trong `fx.js`) dựng hiệu ứng trúng đích từ sprite/hạt có sẵn; chỉ hai nơi trong `combat.js` gọi nó.

**Tech Stack:** JS thuần (không module, treo trên `G`), Node `node:test` (`.cjs`), `new Function('G','document', src)` để nạp file.

**Spec:** `docs/superpowers/specs/2026-10-28-type-vfx-design.md`
