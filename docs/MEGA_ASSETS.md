# Mega sprites — how to add them

Megas are data rows in `js/data/mega.js` (generated by `node tools/fetch_mega.js`, **94 forms**, dex `10000` and up). They are **not** in `G.DEX`.

## What happens with no assets

A Mega with no sheets of its own is drawn with the sheets of its base form plus a pink aura (`core/sprites.js`: `sheetDex`, `isFallback`). So the game works today with zero Mega art.

## Giving a Mega its own sprite

1. Find the dex of the Mega: `G.MEGA_DEX.find(m => m.slug === 'charizard-mega-x').dex` (e.g. `10001`), or read `js/data/mega.js`.
2. Create `assets/pokemon/<megaDex>/` with the same sheets the other Pokémon have (SpriteCollab format): `Idle.png`, `Walk.png`, `Attack.png`, `Shoot.png`, `Charge.png`, `Hurt.png`, `Faint.png`. Optional shiny sheets go in `assets/pokemon/<megaDex>/s/`.
3. Sheet layout: columns = frames, 8 rows = directions (0 Down · 1 DownRight · 2 Right · 3 UpRight · 4 Up · 5 UpLeft · 6 Left · 7 DownLeft). Each animation may have its own frame size.
4. Add the entry to `G.SPRITE_META` in `js/data/sprites-meta.js`, same shape as the others: `"<megaDex>": {"s": ShadowSize, "a": {"Idle": {"w","h","n","r":8,"d":[...],"ax","ay"}, ...}, "sh": 1 if shiny}`. `w,h` = frame size, `n` = frames, `d` = duration of each frame (1/60 s), `ax,ay` = ground anchor inside the frame (the feet).
5. Once `SPRITE_META[megaDex]` exists, the game uses it and stops drawing the aura. Nothing else to change.

`tools/fetch_sprites.py` builds `sprites-meta.js` from SpriteCollab `AnimData.xml`; SpriteCollab has full sheets for only some Megas. This machine has no Python, so run it elsewhere or write the entry by hand.

## Not done

There is no automatic Mega sprite downloader. It would need the SpriteCollab folder layout checked first; until then every Mega uses its base form's sheets with the aura.
